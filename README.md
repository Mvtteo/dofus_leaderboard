# Dofus leaderboard — Nemesis PvP tracker

Classement PvP pour une communauté Dofus : API FastAPI + SQLAlchemy (migrations Alembic), bot Discord (discord.py), client React (Vite), lecture d'images via l'API Groq, déploiement Docker. Détails du backend : `backend/README.md`.

**Démo du client : https://mvtteo.github.io/dofus_leaderboard/** — joueurs et combats **fictifs**, l'API étant simulée dans le navigateur (`demo-api.js` sur la branche `gh-pages`). Aucune donnée réelle de la communauté n'y figure.

## Lancer en local

```bash
docker compose up        # ou voir backend/README.md et client/
```
